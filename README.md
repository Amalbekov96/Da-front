# DA-front

Frontend for [Dispatcher Assistant](https://github.com/Amalbekov96/DA) — Vite + React
+ TypeScript.

## Setup

```bash
npm install
cp .env.example .env   # points at the backend, defaults to http://localhost:8000
npm run dev
```

Requires the backend (`DA` repo) running locally — see its `PROGRESS.md` for setup.

See the backend repo's `PROGRESS.md` for the full project context, what's built, and
next steps (shared handoff doc across both repos).
